```
psql -d t -f database/schema.sql -f database/policies.sql   # للترقية من نسخة قديمة: phase7.sql ثم phase8.sql ثم phase9.sql ثم phase10.sql
psql -d t -f tests/db-rls.test.sql              # آخر سطرين يطبعان عدد النجاح والفشل
```

## النشر على Vercel
1. ارفع مجلد المشروع إلى GitHub (أو استخدم `vercel` من المجلد).
2. Vercel: New Project، اختر المستودع، Framework = Other، دون أمر بناء (موقع ثابت).
3. `vercel.json` يضيف ترويسات الأمان وCSP. `.vercelignore` يمنع نشر database وtests.
4. Supabase > Authentication > URL Configuration: ضع رابط موقعك في Site URL وRedirect URLs.
5. أضف `https://موقعك/reset-password.html` إلى Redirect URLs (شرط لعمل رابط استرداد كلمة المرور). وبريد Supabase الافتراضي محدود الإرسال، فاضبط SMTP خاصاً للإنتاج، وعدّل قالب Reset Password بالعربية.
6. فعّل Confirm email، ورفع الحد الأدنى لكلمة المرور، ومنع كلمات المرور المسرّبة إن توفرت في خطتك.
7. لدومين Supabase مخصص: أضفه إلى connect-src وimg-src وframe-src في vercel.json.
8. بعد النشر افتح Console في المتصفح وتأكد من عدم وجود أخطاء Content-Security-Policy.
